# NorthStar Lab 1 Cost Estimate

The following estimate assumes a small development workload in **AWS us-east-1**. It represents expected monthly usage for the Lab 1 environment rather than production-scale NorthStar workloads.

| Component             | Monthly Estimate | Key Assumptions                                                                                                                                                 | One Optimization                                                                                                                   |
| --------------------- | ---------------: | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| SageMaker Studio      |        **$4.00** | `ml.t3.medium` at $0.05/hr, used 4 hrs/day × 20 days/month = 80 hrs                                                                                             | Stop the Studio compute when not in use; reducing usage from 4 to 2 hrs/day saves about **$2.00/month**                            |
| S3 storage            |        **$0.23** | 10 GB of S3 Standard storage × $0.023/GB-month                                                                                                                  | Move infrequently accessed data to a lower-cost storage class as the dataset grows                                                 |
| Internet Gateway      |        **$0.00** | Internet Gateway itself has no hourly or per-GB charge; assume 10 GB/month of normal development traffic                                                        | Keep the current public-subnet design rather than adding a NAT Gateway, which would introduce an hourly and data-processing charge |
| DynamoDB (state lock) |        **$0.00** | Terraform state locking uses on-demand capacity with only a small number of reads/writes per month; request cost rounds to approximately $0.00 at this workload | Continue using on-demand capacity while state-lock traffic remains low                                                             |
| S3 state bucket       |        **$0.02** | 1 GB of Terraform state/history stored in S3 Standard × $0.023/GB-month                                                                                         | Keep state files small and remove unnecessary historical objects                                                                   |
| **Total**             |        **$4.25** | Small development environment; excludes taxes and unusually high data transfer or API usage                                                                     | Reducing SageMaker usage from 4 to 2 hrs/day reduces the estimate to approximately **$2.25/month**                                 |
